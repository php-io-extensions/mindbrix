# Support

- **Questions and bugs:** open an issue on [php-io-extensions/mindbrix](https://github.com/php-io-extensions/mindbrix/issues). Include `php --ri mindbrix`, your macOS version and Mac, PHP version and build (NTS or ZTS), and the smallest script that shows the problem.
- **How a Rasterizer call behaves:** [`lib/Rasterizer/Package/Sources/RasterizerObjC/include/RasterizerAPI.h`](lib/Rasterizer/Package/Sources/RasterizerObjC/include/RasterizerAPI.h) and its implementation are the reference; this extension adds only what the README's translation section describes.
- **Security problems:** see [SECURITY.md](SECURITY.md); do not open a public issue.
